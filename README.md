**InsurEdge** is a customer-connection and lead-generation platform that connects individuals and families across India with relevant insurance and investment professionals for **Term Insurance**, **Health Insurance**, and **Mutual Funds**.

🌐 **Live Website**: [https://insuredge-cyan.vercel.app](https://insuredge-cyan.vercel.app)  
📖 **About Page**: [https://insuredge-cyan.vercel.app/about](https://insuredge-cyan.vercel.app/about)

---

## 🌟 Core Philosophy

> **Connect first. Understand better. Decide yourself.**
> 
> We don't believe an online platform should make an important financial decision on behalf of a customer. Our role is to make finding the right person to speak with easier.

---

## 🚀 Key Features & Pages

- **Home Page (`/`)**:
  - Hero consultation enquiry form with dynamic financial solutions (Term Insurance, Health Insurance, Mutual Funds).
  - How InsurEdge Works: 3-step transparent advisory connection process.
  - Partner Network & Product Exploration.
  - Testimonials, FAQs, and regulatory compliance disclosures.

- **About Section (`/about`)**:
  - *Why We Started InsurEdge* — person-first approach starting with "What are you looking for?".
  - *Core Philosophy* — Connect first, Understand better, Decide yourself.
  - *Respect for Time & Transparency* — No spam policy, open disclosure of platform economics.
  - *Clear Boundaries* — Detailed "We Are" vs "We Aren't" comparison grid.
  - *Customer Pillars* — Clear, Relevant, Simple, Respectful, Transparent.
  - *Important Regulatory Information* — Transparency & compliance notes.

- **Insurance & Investment Portals**:
  - `/term-insurance` — Term life insurance guidance & comparisons.
  - `/health-insurance` — Comprehensive health insurance plans & cashless hospitalization benefits.
  - `/mutual-funds` — SIP & wealth-building advisory connections.
  - `/calculator` — Interactive coverage & SIP calculations.
  - `/claims` & `/services` — Claim assistance & service portfolio.

- **Design System**:
  - Unified, modern clean white aesthetic (`#F8FAFC`, `#FFFFFF`, slate typography, emerald accents).
  - Fully responsive across desktop, tablet, and mobile devices.

## 💻 Local Development Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/amit0000123/Insuredge.git
   cd Insuredge
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```

4. **Open in browser**:
   Navigate to [http://localhost:3000](http://localhost:3000).

---

## 📦 Production Build

```bash
npm run build
npm run start
```
